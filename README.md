# Workflow Automation Dashboard

A professional workflow management dashboard built using HTML, CSS, and JavaScript.  
This application allows users to manage tasks efficiently using a drag-and-drop interface.

---

## 🔗 Live Demo
https://jayasreem17.github.io/Workflow_AutomationDashboard/

## 💻 GitHub Repository
https://github.com/jayasreem17/Workflow_AutomationDashboard

---

## 🚀 Features

- Add new tasks
- Edit tasks using popup modal
- Delete tasks
- Drag and drop tasks between stages
- Workflow stages:
  - Open
  - In Progress
  - Testing
  - Done
- Real-time task count updates
- Local storage support (data persists after refresh)
- Clean and professional UI
